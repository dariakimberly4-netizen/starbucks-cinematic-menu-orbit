# Starbucks Cinematic Menu Orbit

A responsive, interactive cinematic menu-orbit experience for a Starbucks Philippines concept.

## Vision

The menu is presented as a glowing circular universe rather than a traditional grid. Product categories sit around an illuminated orbit while the selected drink becomes the central hero.

## Core Experience

- Cinematic dark-green coffee-inspired environment
- Gold illuminated concentric orbit rings
- Six main categories: Espresso, Frappuccino®, Refreshers®, Teavana™, Food, and Featured
- Large featured product in the center
- Smaller product satellites on an inner orbit
- Product name, description, price, and Add to Order control
- Swipe and tap interactions
- Responsive mobile and desktop layouts
- Customer/account/order controls

## Design Direction

The interface should remain unmistakably an **orbit**. It should feel premium, immersive, elegant, and coffee-inspired rather than like a standard card or dashboard menu.
